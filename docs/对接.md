# 汐 · 对接说明

情绪与关系账本。它**判断**什么时候该说话；说话本身交给宿主（海螺）。
核心一句话：**她不决定「说得多好听」，她决定「这会儿该不该说、用多大劲」。**

## 一、怎么接

### 1. HTTP（主要）

面板 <http://127.0.0.1:7880/>（本机）。

| 要干的事 | 怎么调 |
|---|---|
| 看状态 | `GET /api/state`（可带 `?person=<人>`） |
| 喂一条消息 | `POST /api/observe {"person": ..., "text": ..., "speaker": "user"}` |
| 问她该不该开口 | 轮询 `GET /api/state` 里的 `wake.wake` |
| 告诉她「发出去了 / 没发成」 | `POST /api/woke {"sent": true}` |
| 身份与能力 | `GET /api/health`、`GET /api/manifest` |
| 设置 / 更新 | `GET /api/settings`、`GET /api/update` |

### 2. 让宿主开口（推荐，已实现）

汐到线时 → `POST {host}/api/proactive/say` → 宿主用自己的嘴发 → 回 `POST {汐}/api/woke` 或宿主的 `report_url`。
字段、时序、失败语义全在 [主动消息-对接.md](主动消息-对接.md)。

### 3. MCP / 插件

`汐/plugins/mood/` 是海螺那边的小适配器：`message.observed` → observe，`speech.prompt` → 说话分寸，
`speech.gate` → 记「谁先开的口」（这决定缓解期和好感怎么走）。

## 二、能力清单

- 情绪与需求随时间自然变化（想念、无聊、担心、饿、渴、精力）
- 按人和关系记好感、记仇、缓解
- 判断该不该主动开口：冷却 / 免打扰 / 每日上限 / 连续没回复上限
- 生成「说话的分寸」那一段提示词

## 三、失败语义

| 情况 | 返回 | 调用方怎么做 |
|---|---|---|
| 宿主没配 | `host.enabled: false` | 汐退回自带的那张嘴（`wake.auto_send`），或只推进状态不说话 |
| 宿主没应（HTTP 失败） | `{"ok": false, "error": ...}` | 汐**不记账**，隔 `retry_min` 分钟再试；过期就丢掉别补发 |
| 宿主说发出去了 | `sent: true` | 才算「主动过」，才进冷却、才记今天第几次 |
| 宿主说没发成 | `sent: false` | **绝不能当成功**：不记进冷却、不加 wake 次数，只记一次失败 |

这条是这套东西里最容易写错的地方：**「请求发出去」不等于「消息发出去」**。

## 四、单独运行（不装海螺）

```powershell
cd <插件目录>\汐
python -m tide.panel --brain          # 真要她自己发，再配 config/local.yaml 里的 wake.auto_send 和 QQ
```

面板能看情绪曲线、关系账本、未来 24 小时走势；不配宿主就只有面板，不会主动打扰你。
