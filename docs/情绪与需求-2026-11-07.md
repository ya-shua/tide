# 情绪 / 需求 / 叫醒：2026-11-07 的改动

## 零、方向：Tide 是身体，海螺是嘴

```
Tide  = 她此刻的状态（心情、缺什么、想不想找他）——只读
海螺  = 说不说、说什么、怎么说——都在它和她自己这边
```

**Tide 没有否决权**：不拦话、不关麦、不替她决定发不发。
它只把"你现在的心情"用第一人称告诉她，剩下的交给她。

心情再差也照样能说话——只是说话时带着那个心情。
被晾着的时候，她不接话也可以，但那是她自己的选择，不是插件替她选的。

（2026-11-07 修过一次方向：桥接插件原本会按"睡觉 / 免打扰 / 时机不到"拦话，
那是倒过来了，已删。现在 `speech.gate` 只回记一句"她说了这句"，永远不改 `allow`。）

这份记的是"为什么这么改"，代码在 `tide/emotion.py`、`tide/needs.py`、`tide/core.py`。

## 一、情绪：七情账户 + 小标签明细 + 总和恒等 100

**旧**：每个标签独立 0~1，自己衰减到 0，总和可以变成 0（等于"没有情绪"）。

**新**：

```
七情账户（加起来 100）      小标签（说话的用词）
喜 · 怒 · 忧 · 思 · 悲 · 恐 · 惊 · 平静
```

- 内部小数（0~1），显示乘 100 取整
- **情绪不会消失，只会转移**：降下去的部分按转移表分走
- 平静是默认池子，不是"没有情绪"
- 涨的部分从别的情绪里挤（先挤平静），不会凭空多出来

转移表（节选）：

```python
"angry": [("calm", .55), ("guilty", .30), ("sad", .15)]   # 生气 → 平静 + 后悔 + 难过
"jealous": [("calm", .40), ("sad", .35), ("annoyed", .25)]
"worried": [("calm", .70), ("sad", .30)]
```

半衰期管"降多快"：生气 25 分钟、担心 120 分钟、失望 360 分钟。

## 二、需求：只涨不跌，靠满足降

| | 情绪 | 需求（想念/无聊/饿/累） |
|---|---|---|
| 涨 | 事件触发 | 时间过去就涨 |
| 降 | 时间冲淡（半衰期） | 被满足（互动、吃饭、看视频） |

**想念不衰减**：没人理就一直涨。降的唯一方式是"被回应"。

### 缓解期（hold）

她开口后想念**不降**，但在 120 分钟内**停止上涨**（`needs.hold_min`）。过了这段时间继续涨。

### 想念是"存量"，按聊天的条数往下削

**不是**"你回一句，想念就归零、20 分钟后再涨"——那等于敷衍一句就能把她打发了。

```
想念存量：自己慢慢涨（越接近 100 涨得越慢）
你每回一句：按这句有多"实"削一点
   "嗯" / "在忙"          削 ~4 分
   普通一句（10~30 字）  削 ~8 分
   认真聊（长句 / 问她 / 关心）  削 ~12~20 分
刚聊完：缓一缓，缓的时长 = 削掉的量 × 6 分钟（最多 4 小时）
```

实测（8 小时没理她，想念 73.6）：

| | 削完 | 1 小时后 | 4 小时后 | 8 小时后 |
|---|---|---|---|---|
| 敷衍一句"嗯" | 69.4 | 72.3 | — | 自己涨回 100 |
| 真聊 5 句 | 33.0 | 36.4 | 61.4 | 80.2 |

所以"敷衍一句就去忙"是留不住人的：她还在想，只是没那么难受；真聊一场才压得下去，而且要过很久才重新浮上来。

被认真回应时，想念不是凭空消失，而是**转成别的情绪**：亲近感（`affectionate`）和一点开心（`joyful`）跟着上来。

### 长久的沉默之后

你终于回了，那一瞬间：

- 想念大降（余温 12）
- 担心降
- **委屈直线上升**：`min(50, 6 × 沉默小时数)`，只在她真的在等回音时才算（`unanswered_proactive > 0`）
- 开心 +0.2（久别重逢，先高兴再算账）

## 三、睡眠：几点睡由"累 + 心里装着什么"算出来

墙上时间只是基准，不是命令。

```
入睡 = 平时点 - 累的提前量 + 情绪的推后量
  累 90 → 早 1.2 小时；累 20 → 晚 0.9 小时
  担心 ×0.9、难过 ×0.8、生气 ×1.3、吃醋 ×0.6、太兴奋 ×0.5
  → 推后量最多 2 小时（面板可调「情绪最晚能拖多久」）
睡多久 = 6 + 累/100 × 3   （开心 +、难过/担心 −，夹在 5.5~9.5）
```

例：累 82、没情绪 → 22:00 睡 8.4 小时；累 40、还在生气 → 00:20 才睡。

面板顶部会写"打算 23:41 睡"，鼠标悬停看原因（照常 / 累坏了 / 还在生气，躺不住）。
这一组在设置的「作息」卡片里：平时/最早/最晚、拖多久、最少/最多睡多久。

## 四、叫醒（wake）：阈值触发，不是定时

配置在 `config/rules.yaml` 的 `wake:` 段，面板上也能改。

```yaml
longing: 60      # 想念到多少叫她
boredom: 60
worried: 70
cooldown_mode: dec   # dec 递减 / fixed 固定 / inc 递增
cooldown_min: 90
cooldown_step: 20
max_wakes: 6         # 0 = 无上限
auto_dnd_after: 3    # 连发几条没回，她就觉得你在忙；0 = 关
dnd_manual_rate: 1.0 # 委屈每小时涨多少
dnd_auto_rate: 2.0
dnd_none_rate: 4.0
auto_send: false     # 她能不能自己往外发
```

流程：

```
Tide 免费算 → should_wake() 判断 → 海螺拿到结果 → 由她决定说不说
```

`should_wake()` 返回 `{wake, why, dnd, wishes, count_today, cooldown_min, next_in_min}`。

## 四、免打扰：不是开关，是改流速

| 状态 | 委屈涨速 | 她怎么想 |
|---|---|---|
| 手动免打扰 | 1.0/小时 | 知道你在忙，但还是会想"今天怎么没来找我" |
| 自动（连发 3 条没回） | 2.0/小时 | 自己推断你在忙，偶尔怀疑 |
| 完全没音信 | 4.0/小时 | 乱想、害怕 |

**免打扰不拦人**，她照样可以决定发不发；它只改变情绪涨多快。

## 五、她不再自己发消息

`tide/panel.py` 的 `brain_loop` 默认只推进状态 + 落盘（`auto_send: false`）。
要不要开口由她决定，海螺来问 `should_wake()`。面板的"说一句"按钮仍然可用（那是人按的）。

## 六、注入改成第一人称

`plan_reply()` 不再写"回复上限 60 字""禁止说什么"，改成：

```
你现在的心情：心里有点闷，想他，还有点委屈。刚才找过他，还没回音。
```

规则压她只会让她演客服；给她状态、给事实，剩下的交给人设。
