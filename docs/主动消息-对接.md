# 主动消息：Tide 判断，宿主开口

一句话：**Tide 是身体，宿主是嘴。**

Tide 只回答「我现在想不想找他、该不该说话」；说什么、什么口吻，交给有角色的那边。
海螺有人设、有对话历史，所以这句话应该由海螺说 —— 自己拼模板句的话，
你回一句「啥？」，她接不上，因为那句不在她的上下文里。

这份文档是对外契约，**不绑海螺**：任何宿主（自己的 QQ 桥、别家的 agent、一个脚本）
照着实现两个端点就能接上；不接也能用（退回 Tide 自带的那张嘴）。

---

## 一、时序

```
        你（人）
          │  不回她
          ▼
Tide 每分钟推进一次状态（不花钱）
          │  想念越过门槛的那一下（只在"从不该变该"那一瞬）
          ├──► POST {host}/api/proactive/say     ← 通知：她想找你说句话
          │         {event_id, why, urgency, needs, person, report_url}
          │    ◄── {"ok": true, "accepted": true}
          │
   宿主：用自己的人设 + 模型说一句 → 发到 QQ
          │
          └──► POST {report_url}                  ← 回执：说成了没有
                    {event_id, sent, text, error}
                    ◄── {"ok": true, "sent": true}
```

- **不是轮询**：只在跨过门槛那一次通知，之后 Tide 记着「已经通知了」等回执；
  回执回来才结束这一轮，下一个 60 秒它不会再翻。
- 冷却、每天上限、免打扰、没回音停发，全部是 Tide 原有的设置（`config/rules.yaml` 的
  `wake` 段 + 面板「主动」那几格），接宿主**不用新增任何参数**。

---

## 二、Tide 调用宿主（宿主必须实现）

```http
POST {host.url}/api/proactive/say
Content-Type: application/json
x-console-token: {host.token}

{
  "event_id": "t1793000000-a1b2c3",     // 这一次的唯一号，回执原样带回
  "why": "想你 91",                      // 为什么想开口（给人看的，可以念进提示词）
  "urgency": 87.4,                       // 急不急（加权分，仅供参考）
  "needs": {"hunger": 68.7, "thirst": 42.6, "energy": 41.5,
            "longing": 90.6, "boredom": 41.8},
  "person": "主人",                      // 她心里那个人
  "count_today": 0,                      // 今天已经找过几次
  "report_url": "http://127.0.0.1:7880/api/proactive-report"
}
```

返回：

```json
{"ok": true,  "accepted": true}            // 接了，正在说（说完回执）
{"ok": false, "error": "没开主动开口"}      // 不接 —— Tide 会退避，不会一直敲
```

**要求宿主立刻返回**（几毫秒），真说话放后台：跑一次模型要几秒，
不能让 Tide 那 5 秒超时把它掐了。

---

## 三、宿主回执 Tide（必须实现）

```http
POST {report_url}
Content-Type: application/json

{"event_id": "t1793000000-a1b2c3", "sent": true,  "text": "在吗", "error": ""}
{"event_id": "t1793000000-a1b2c3", "sent": false, "text": "",     "error": "OneBot 断线"}
```

Tide 收到之后：

| sent | Tide 做什么 |
|---|---|
| `true` | 记「上次主动时间」（冷却开始）、今天叫醒次数 +1、记忆里记一条「主动找你：…」 |
| `false` | **什么都不记**，只留一笔失败日志，退避 `retry_min` 分钟后才允许再试 |

**失败必须如实上报。** 报成功但其实没发出去，Tide 会以为她说过了：
冷却 90 分钟、想念冻结，等不到回音还会开始委屈 —— 全都是错怪你。

回执的 `event_id` 对不上时 Tide 直接忽略（重复回执/乱回都不会记账）。

---

## 四、还差一件事：她「说过这句」要进 Tide 的记忆

回执只管主动这件事本身。Tide 的「没回音计数」和「缓解期」是靠
**她真的说出那句话**触发的，走的是已有的：

```http
POST http://127.0.0.1:7880/api/observe
{"text": "在吗", "speaker": "self", "initiated": true}
```

海螺那边这一步是自带的心情插件在做（`speech.gate` 里对 `feature=proactive` 记一笔），
**别的宿主如果没这个插件，就要自己补这一次 observe**，否则：
- 没回音计数不涨 → 你一直不回，它也一直不知道你在忙
- 缓解期不开 → 想念继续涨，冷却一过又想说

---

## 五、不接宿主也能用

`config/local.yaml` 里不写 `host` 段（或 `enabled: false`）时：

- 到线了 Tide 用自带的那张嘴发（`config/rules.yaml` 的 `wake.auto_send: true`）
- 发的是 `say.py` 拼的模板句，**没有人设、不进任何对话历史**

这保证了插件单独拿出去、没有宿主也能跑通；接了宿主才有「她用自己的嘴说」的效果。

---

## 六、配置

```yaml
# config/local.yaml（不进仓库）
host:
  enabled: true
  url: "http://127.0.0.1:7801"      # 宿主面板
  token: "<宿主面板 token>"
  panel_port: 7880                   # 宿主回执打到这个端口的 /api/proactive-report
  wait_sec: 300                      # 通知完等回执多久算失败
  retry_min: 10                      # 失败后隔多久才允许再试
```

宿主那边（以海螺为例）：

```json
"proactive": {
  "enabled": true,
  "conv_id": "private:<主人QQ>",
  "report_url": "http://127.0.0.1:7880/api/proactive-report",
  "report_timeout_sec": 8
}
```

## 七、自测

宿主起好之后，直接打它一下（不会等到线）：

```powershell
curl.exe -s -X POST http://127.0.0.1:7801/api/proactive/say `
  -H "content-type: application/json" -H "x-console-token: dev-token" `
  -d '{\"event_id\":\"manual-test\",\"why\":\"手动测试\",\"report_url\":\"http://127.0.0.1:7880/api/proactive-report\"}'
```

返回 `{"ok":true,"accepted":true}` 说明接住了；过几秒看她私聊有没有那句，
Tide 的 `data/state.json` 里 `wake_marks` 会多一个时间戳。

**不想现在真发**：把海螺 `proactive.enabled` 设成 `false`，端点会拒绝，Tide 记一笔「宿主没收」。

## 八、两条踩过的坑（v1.4.1）

1. **同一台机器只能有一个 Tide 在推进时间。** Windows 默认允许两个进程绑同一个端口，
   于是两个 Tide 各跑各的时钟、共用一份 `state.json`：这边刚说完、那边两分钟后又冒一句，
   冷却看起来完全失效。现在面板 `allow_reuse_address = False` + `data/panel.lock`，
   第二个实例起来会直接打印「已经有一个面板在跑了」并退出。你要是自己写宿主，也别把
   Tide 起成多份。
2. **一次开口只该记一笔。** 宿主回执（`sent:true`）记一次叫醒，mood 插件的
   `speech.gate`（她真的说出去了）也会记一次 —— 两边都调 `mark_woke`。
   `mark_woke()` 现在 30 秒内的重复会合并成一笔；调它不用自己避重。
   如果你不跑 mood 插件，回执那次就是唯一那笔，行为不变。
