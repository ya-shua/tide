# 关系与分寸

Tide 记两样东西：**她对每个人的好感**（独立、慢慢变），**她此刻的心情**（一份、会退）。
说话的时候两样叠起来，决定这一句是黏、是客气、还是一点就炸。

---

## 1. 谁算一个人

| 说话的人 | 记在谁头上 |
| --- | --- |
| 自己人（海螺「称呼卡」上的号，含同一人的多个号） | Tide 默认那个人（`default_person`，默认「主人」） |
| 其他私聊 | `qq:<QQ号>` |
| 群里其他人 | `qq:<QQ号>`（就地按人，不按群） |

关键在于：**关系按人记，不按会话记**。同一个人的两个号、在群里和在私聊，
都是同一份好感和委屈；群里 A 和 B 各有一份，互不影响。

面板和提示词里显示成人话：`qq:777888` → `QQ 777888`，`group:…`（老数据）→ `群 …`。

---

## 2. 好感（亲和 / 委屈）

每人一套，结构：

| 字段 | 范围 | 说明 |
| --- | --- | --- |
| `affinity` | 0–100 | 亲和。涨得慢、掉得快 |
| `trust` | 0–100 | 信任 |
| `grievance` | 0–100 | 委屈，分三档（见下） |

委屈不是一条直线，每档有自己的地板：

| 档 | 委屈 | 怎么好 | 地板 |
| --- | --- | --- | --- |
| 小生气 | 15–34 | 哄一句就化，时间也能磨 | 0 |
| 中生气 | 35–64 | 必须**道歉 + 哄**两样都出现 | 36 |
| 大生气 | ≥65 | 认错只缩短冷静时间，真正的解药是等 | 66（没冷静完） |

地板之上按 90 分钟半衰期往下走。

---

## 3. 分寸：好感 × 心情

提示词里多一行「说话的分寸」，由「对这个人多亲近」×「此刻是哪一情」算出来。

| | 心情好 | 一般 | 生气 |
| --- | --- | --- | --- |
| **好感高** | 可以黏一点、多说两句 | 放松点说 | 压着火说，别撂狠话 |
| **好感一般** | 客气点，不必热络 | 正常说 | 克制着说，别翻旧账 |
| **好感低** | 客气点，不必热络 | 正常说 | 可以冲，话要短，别哄 |

难过 / 担心 / 想你也是同一套逻辑：亲近的人面前可以露，不熟的人面前收着。

### 怒气优先

「喜欢」这个情绪（`affectionate`）半衰期 12 小时，数值会一直很高。
如果只看「谁最强」，气头上也压不过它，写出来就成了「心情好」。

所以有单独的判定：

```python
def dominant(self):
    anger = max(angry, annoyed, jealous)
    if anger >= calm_threshold:
        return "anger", anger
    ...
```

**在气头上，语气一律按怒气算**，别的情绪让路。

## 4. 提示词长什么样

```
你现在的心情：心里很想亲近他，很生气。
需求：饿 22｜累 38｜想你 18｜无聊 16
关系：亲和 88｜委屈 40（sulky·还差：道歉 + 哄）
说话的分寸：在生气，但跟他关系近——压着火说，别撂狠话。
话题：closed｜没在等
```

约 80 字，≈ 55 token。**只注入当前说话这个人那一份**，Tide 里存着几个人都不影响这一段的长度。

## 5. 配置

`config/rules.yaml` 的 `bond` 段落调这些：

```yaml
bond:
  tiers: { mild: 15, mid: 35, big: 65 }   # 三档委屈的界线
  grievance_half_life_min: 90             # 委屈往地板走的速度
  calm_hours: 6                           # 大生气默认冷静多久
  calm_min_hours: 1.5                     # 哄到位后最少还要多久
  apology_shorten: 0.6                    # 道歉能缩短多少
  comfort_shorten: 0.8                    # 哄能缩短多少
  init_affinity: 50
  init_trust: 60
  init_grievance: 0
```
